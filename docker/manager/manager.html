      Process Image

      Live values of all KBUS channels. Outputs are switched at once; another program that writes the same outputs (e.g. CODESYS) overwrites them in its next cycle, unless you take local control.

      COM1

      The gateway forwards COM1 transparently over WDX (Serial/Com1/...). The settings are made on the client side: CODESYS sets them with FB_WdaSerial (inputs udiSetBaudrate, sSetFormat, uiSetFrameGap); this page shows them. RS-232 / RS-485 is set in the WBM (Interfaces > Serial Interface, owner "None").

      COM1 is off in the gateway (SERIAL_DEVICE empty).
