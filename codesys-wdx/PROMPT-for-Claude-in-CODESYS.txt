TASK: CODESYS application with KBus I/O through the wdx data layer of kbus-gateway
Please build this in the open CODESYS project. All information and the complete code are below.

GOAL
A CODESYS 3.5 application on a WAGO PFC300 (750-8302) that controls the outputs and reads
the inputs of the KBus modules through the wdx-style data layer of the kbus-gateway
(HTTP, JSON:API), NOT through the KBus. Speed and constant timing are important.

ENVIRONMENT
- The kbus-gateway runs natively on the same controller and owns the KBus:
  127.0.0.1, TCP port 8000. The project must NOT contain a KBus node in the device tree.
- Current modules: 8 digital outputs (DO1..DO8), no inputs yet.

WDX DATA LAYER (exact)
- Parameters: path KBus/DigitalOutputValues -> id 0-0-kbus-digitaloutputvalues
  (id = '0-0-' + lower-case path, '/' -> '-'). Arrays of a whole class:
    0-0-kbus-digitalinputvalues   boolean[] read-only
    0-0-kbus-digitaloutputvalues  boolean[] writable
    0-0-kbus-analoginputvalues    uint16[]  read-only (raw)
    0-0-kbus-analogoutputvalues   uint16[]  writable (raw)
- Write all DO (one TCP write, CODESYS notation, $R$N = CR LF):
    'PATCH /wda/parameters/0-0-kbus-digitaloutputvalues HTTP/1.0$R$N'
    'Content-Type: application/vnd.api+json$R$N$R$N'
    '{"data":{"type":"parameters","id":"0-0-kbus-digitaloutputvalues","attributes":{"value":[true,false,...]}}}'
  -> 'HTTP/1.0 204 No Content' with 'Content-Length: 0'
- Read all in ONE request (one KBus snapshot):
    'GET /wda/parameters?filter[id]=0-0-kbus-digitalinputvalues,0-0-kbus-digitaloutputvalues HTTP/1.0$R$N$R$N'
  -> 200, compact JSON (no spaces):
    {"data":[{"type":"parameters","id":"0-0-kbus-digitaloutputvalues","attributes":{"path":"KBus/DigitalOutputValues","dataType":"boolean","dataRank":"array","value":[true,false,...]}}],"meta":{...}}
- Every answer has Content-Length: the answer is complete when that many body bytes arrived.
- The gateway reads each request ONCE (max 4096 bytes): send the whole request in ONE TCP_Write.
- It serves ONE client at a time: never run requests in parallel; close on time-out.
- Status: 200, 204, 400 malformed/mismatch, 403 writes disabled, 404 unknown id,
  409 read-only / out of range / more values than channels, 415 wrong Content-Type.
- Standard string functions (CONCAT/MID/FIND) handle at most 255 characters; requests and
  answers can be longer, so the code uses byte buffers (F_AppendStr, F_FindBytes).

DESIGN FOR SPEED (keep it)
- Fixed sequence per exchange: PATCH DO array (if DO), PATCH AO array (if AO), one GET.
- Several stages per task cycle (connect -> send -> receive), next request in the same cycle.
- Receive ends on Content-Length, not on connection close.

EXISTING PROJECT (switch from /ALL to the wdx data layer)
The project may already contain an older version that used 'POST /ALL' (bulk REST):
GVL_KbusRest, F_AppendStr, FB_HttpTransaction, FB_KbusRestIo, PLC_PRG.
- REPLACE the existing objects with the same names by the code below
  (FB_HttpTransaction changed: it now ends on Content-Length and needs F_FindBytes).
- DELETE FB_KbusRestIo: FB_WdxKbusIo replaces it.
- Keep everything else in the project. If other code uses FB_KbusRestIo, change it to
  FB_WdxKbusIo: same inputs (xEnable, uiNumDI/DO/AI/AO, axDOSet, auiAOSet, tInterval,
  tTimeout) and outputs (axDI, auiAI, axDO, auiAO, xOnline, udiErrors, tLastExchange,
  sLastError, udiExchanges); iLastStatus is new.
- Since gateway version 2.0.0 the wdx data layer is the ONLY interface: 'POST /ALL' and

OBJECT: F_AppendStr
==================================================================================
// ===========================================================================
// F_AppendStr  -  append the bytes of a STRING to a byte buffer
// Object type in CODESYS: POU, Function, return type BOOL, language ST
//
// Used to build HTTP requests longer than 255 characters (the Standard
// library string functions CONCAT/MID/FIND are limited to 255 characters).
// Returns FALSE when the buffer was full and the text was cut off.
// ===========================================================================
FUNCTION F_AppendStr : BOOL
VAR_INPUT
    pBuf    : POINTER TO BYTE;      // start of the buffer
    udiCap  : UDINT;                // size of the buffer in bytes
    sText   : STRING(80);           // text to append
END_VAR
VAR_IN_OUT
    udiLen  : UDINT;                // bytes used in the buffer (updated)
END_VAR
VAR
    pS      : POINTER TO BYTE;
    i       : UDINT;
END_VAR

// --- implementation --------------------------------------------------------
pS := ADR(sText);
i := 0;
WHILE (pS[i] <> 0) AND (udiLen < udiCap) DO
    pBuf[udiLen] := pS[i];
    udiLen := udiLen + 1;
    i := i + 1;
END_WHILE
F_AppendStr := (pS[i] = 0);

OBJECT: F_FindBytes
==================================================================================
// ===========================================================================
// F_FindBytes  -  find a text in a byte buffer
// Object type in CODESYS: POU, Function, return type DINT, language ST
//
// Returns the 0-based position of sPattern in pBuf[udiFrom..udiLen-1], or -1.
// Works on buffers longer than 255 characters (Standard FIND does not).
// ===========================================================================
FUNCTION F_FindBytes : DINT
VAR_INPUT
    pBuf     : POINTER TO BYTE;
    udiLen   : UDINT;               // bytes in the buffer
    udiFrom  : UDINT;               // start position (0-based)
    sPattern : STRING(80);
END_VAR
VAR
    pP       : POINTER TO BYTE;
    udiPLen  : UDINT;
    i        : UDINT;
    j        : UDINT;
    xMatch   : BOOL;
END_VAR

// --- implementation --------------------------------------------------------
F_FindBytes := -1;
udiPLen := TO_UDINT(LEN(sPattern));
pP := ADR(sPattern);
IF (udiPLen = 0) OR (udiLen < udiPLen) THEN
    RETURN;
END_IF
i := udiFrom;
WHILE i + udiPLen <= udiLen DO
    xMatch := TRUE;
    j := 0;
    WHILE xMatch AND (j < udiPLen) DO
        IF pBuf[i + j] <> pP[j] THEN
            xMatch := FALSE;
        END_IF
        j := j + 1;
    END_WHILE
    IF xMatch THEN
        F_FindBytes := TO_DINT(i);
        RETURN;
    END_IF
    i := i + 1;
END_WHILE

OBJECT: FB_HttpTransaction
==================================================================================
// ===========================================================================
// FB_HttpTransaction  -  ONE HTTP request (byte based, fast completion)
// Object type in CODESYS: POU, Function Block, language ST
// Library: CAA Net Base Services (namespace NBS) + Standard
//
// Flow: connect -> send the complete request in ONE TCP write -> receive ->
// status code + body position. Speed:
//   - several stages run in the SAME task cycle where the library allows it
//     (connected -> send at once, sent -> read at once, complete -> parse)
//   - the answer is complete as soon as Content-Length bytes of body arrived
//     (the wdx interface always sends Content-Length); otherwise when the
//     server closes the connection, or 20 ms after the last data
//
// Gateway rules this FB respects:
//   - the gateway reads ONCE: the request must be one TCP write
//   - one client at a time: never run two transactions in parallel
//
// Usage: set pRequest/udiRequestLen, rising edge on xExecute, wait for xDone
//        or xError, then xExecute := FALSE (a FALSE->TRUE in the same cycle
//        starts the next request immediately).
// ===========================================================================
FUNCTION_BLOCK FB_HttpTransaction
VAR_INPUT
    xExecute      : BOOL;
    sHost         : STRING(15) := GVL_KbusRest.gc_sGatewayHost;
    uiPort        : UINT       := GVL_KbusRest.gc_uiGatewayPort;
    pRequest      : POINTER TO BYTE;
    udiRequestLen : UDINT;
    tTimeout      : TIME := T#1S;
END_VAR
VAR_OUTPUT
    xBusy         : BOOL;
    xDone         : BOOL;                                // valid HTTP answer (any status)
    xError        : BOOL;                                // no valid answer
    iStatus       : INT;                                 // 200, 204, 4xx; 0 = no answer
    pBody         : POINTER TO BYTE;
    udiBodyLen    : UDINT;
    sErrorText    : STRING(80);
END_VAR
VAR
    fbConn        : NBS.TCP_Connection;
    fbWrite       : NBS.TCP_Write;
    fbRead        : NBS.TCP_Read;
    ipAddr        : NBS.IP_ADDR;
    rtExecute     : R_TRIG;
    fbTimeout     : TON;
    fbIdle        : TON;
    iState        : INT;
    iPrev         : INT;
    iLoop         : INT;
    abChunk       : ARRAY[0..1023] OF BYTE;
    abRx          : ARRAY[0..4095] OF BYTE;
    udiRx         : UDINT;
    diHdrEnd      : DINT;                                // position of CR LF CR LF, -1 = not yet
    diCLen        : DINT;                                // Content-Length, -1 = none
    diPos         : DINT;
    sHead         : STRING(80);
    pHead         : POINTER TO BYTE;
    i             : UDINT;
    udiMax        : UDINT;
    xComplete     : BOOL;
END_VAR

// --- implementation --------------------------------------------------------
rtExecute(CLK := xExecute);

// up to 4 stages per call: no task cycle is wasted between finished stages
FOR iLoop := 1 TO 4 DO
    iPrev := iState;
    CASE iState OF
    0:  // idle
        IF rtExecute.Q THEN
            xBusy := TRUE; xDone := FALSE; xError := FALSE;
            iStatus := 0; pBody := ADR(abRx); udiBodyLen := 0; sErrorText := '';
            udiRx := 0; diHdrEnd := -1; diCLen := -1;
            ipAddr.sAddr := sHost;
            IF (pRequest = 0) OR (udiRequestLen = 0) THEN
                sErrorText := 'no request';
                iState := 99;
            ELSE
                iState := 10;
            END_IF
        END_IF

    10: // connect
        fbConn(xEnable := TRUE, ipAddr := ipAddr, uiPort := uiPort);
        IF fbConn.xActive THEN
            iState := 20;
        ELSIF fbConn.xError THEN
            sErrorText := 'connect failed (gateway running? port?)';
            iState := 99;
        END_IF

    20: // send the whole request in ONE write
        fbConn(xEnable := TRUE, ipAddr := ipAddr, uiPort := uiPort);
        fbWrite(xExecute := TRUE, hConnection := fbConn.hConnection,
                szSize := udiRequestLen, pData := pRequest);
        IF fbWrite.xDone THEN
            fbWrite(xExecute := FALSE);
            iState := 30;
        ELSIF fbWrite.xError THEN
            fbWrite(xExecute := FALSE);
            sErrorText := 'send failed';
            iState := 99;
        END_IF

    30: // receive
        fbConn(xEnable := TRUE, ipAddr := ipAddr, uiPort := uiPort);
        fbRead(xEnable := TRUE, hConnection := fbConn.hConnection,
               szSize := SIZEOF(abChunk), pData := ADR(abChunk));
        IF fbRead.xReady AND fbRead.szCount > 0 THEN
            FOR i := 0 TO TO_UDINT(fbRead.szCount) - 1 DO   // szCount is CAA.SIZE (64 bit on ARM64)
                IF udiRx < SIZEOF(abRx) THEN
                    abRx[udiRx] := abChunk[i];
                    udiRx := udiRx + 1;
                END_IF
            END_FOR
            fbIdle(IN := FALSE);
            // header complete? then read Content-Length once
            IF diHdrEnd < 0 THEN
                diHdrEnd := F_FindBytes(ADR(abRx), udiRx, 0, '$R$N$R$N');
                IF diHdrEnd >= 0 THEN
                    diPos := F_FindBytes(ADR(abRx), TO_UDINT(diHdrEnd), 0, 'Content-Length: ');
                    IF diPos >= 0 THEN
                        diCLen := 0;
                        i := TO_UDINT(diPos) + 16;
                        WHILE (i < udiRx) AND (abRx[i] >= 48) AND (abRx[i] <= 57) DO
                            diCLen := diCLen * 10 + (abRx[i] - 48);
                            i := i + 1;
                        END_WHILE
                    END_IF
                END_IF
            END_IF
        END_IF
        xComplete := (diHdrEnd >= 0) AND (diCLen >= 0) AND (TO_DINT(udiRx) >= diHdrEnd + 4 + diCLen);
        fbIdle(IN := udiRx > 0, PT := T#20MS);
        IF xComplete OR ((udiRx > 0) AND (fbRead.xError OR NOT fbConn.xActive OR fbIdle.Q)) THEN
            iState := 40;
        ELSIF (udiRx = 0) AND (fbRead.xError OR NOT fbConn.xActive) THEN
            sErrorText := 'connection closed without answer';
            iState := 99;
        END_IF

    40: // parse status line and body position, close
        udiMax := MIN(udiRx, 80);
        pHead := ADR(sHead);
        FOR i := 0 TO udiMax - 1 DO
            pHead[i] := abRx[i];
        END_FOR
        pHead[udiMax] := 0;
        IF FIND(sHead, 'HTTP/1.') = 1 AND LEN(sHead) >= 12 THEN
            iStatus := STRING_TO_INT(MID(sHead, 3, 10));    // 'HTTP/1.0 200 OK' -> '200'
        END_IF
        IF diHdrEnd < 0 THEN
            diHdrEnd := F_FindBytes(ADR(abRx), udiRx, 0, '$R$N$R$N');
        END_IF
        IF diHdrEnd >= 0 THEN
            pBody := ADR(abRx[diHdrEnd + 4]);
            udiBodyLen := udiRx - TO_UDINT(diHdrEnd + 4);
        END_IF
        fbRead(xEnable := FALSE, hConnection := fbConn.hConnection);
        fbConn(xEnable := FALSE);
        fbIdle(IN := FALSE);
        xBusy := FALSE;
        IF iStatus > 0 THEN
            xDone := TRUE;
        ELSE
            xError := TRUE;
            sErrorText := 'no valid HTTP answer';
        END_IF
        iState := 0;

    99: // error: close everything
        fbWrite(xExecute := FALSE);
        fbRead(xEnable := FALSE, hConnection := fbConn.hConnection);
        fbConn(xEnable := FALSE);
        fbIdle(IN := FALSE);
        xBusy := FALSE;
        xError := TRUE;
        iState := 0;
    END_CASE

    // stop when nothing changed (waiting for the network) or finished
    IF (iState = iPrev) OR (iState = 0) THEN
        EXIT;
    END_IF
END_FOR

// overall time-out (also releases the gateway, which serves one client at a time)
fbTimeout(IN := (iState >= 10) AND (iState < 40), PT := tTimeout);
IF fbTimeout.Q THEN
    sErrorText := 'timeout';
    fbWrite(xExecute := FALSE);
    fbRead(xEnable := FALSE, hConnection := fbConn.hConnection);
    fbConn(xEnable := FALSE);
    xBusy := FALSE;
    xError := TRUE;
    iState := 0;
END_IF

// ===========================================================================
// FB_WdxKbusIo  -  cyclic KBus I/O through the wdx data layer of kbus-gateway
// Object type in CODESYS: POU, Function Block, language ST
// Uses: FB_HttpTransaction, F_AppendStr, F_FindBytes, GVL_KbusRest
// Needs kbus-gateway 1.1.0 or newer (wdx interface /wda/parameters, filter[id]); 2.0.0 has only this interface.
//
// Every exchange is the SAME fixed sequence (constant timing):
//   1. PATCH /wda/parameters/0-0-kbus-digitaloutputvalues   (if uiNumDO > 0)  -> 204
//   2. PATCH /wda/parameters/0-0-kbus-analogoutputvalues    (if uiNumAO > 0)  -> 204
//   3. GET   /wda/parameters?filter[id]=<all value arrays>                    -> 200
//      reads all inputs and confirms the outputs, from one KBus snapshot
// The next step starts in the same task cycle as the previous one finished.
// Every PATCH carries the complete output array, so outputs are restored
// automatically after a gateway restart.
//
// Set uiNumDI/DO/AI/AO to the channel counts of the gateway, e.g. from
//   GET /wda/parameters/0-0-kbus-digitaloutputs   (instantiations [1..8])
// ===========================================================================
FUNCTION_BLOCK FB_WdxKbusIo
VAR_INPUT
    xEnable       : BOOL;
    sHost         : STRING(15) := GVL_KbusRest.gc_sGatewayHost;
    uiPort        : UINT       := GVL_KbusRest.gc_uiGatewayPort;
    uiNumDI       : UINT;
    uiNumDO       : UINT;
    uiNumAI       : UINT;
    uiNumAO       : UINT;
    tInterval     : TIME := T#0MS;                       // 0 = exchange back to back
    tTimeout      : TIME := T#500MS;                     // per request
    axDOSet       : ARRAY[1..GVL_KbusRest.gc_uiMaxDigital] OF BOOL;  // desired DO
    auiAOSet      : ARRAY[1..GVL_KbusRest.gc_uiMaxAnalog]  OF UINT;  // desired AO (raw)
END_VAR
VAR_OUTPUT
    axDI          : ARRAY[1..GVL_KbusRest.gc_uiMaxDigital] OF BOOL;
    auiAI         : ARRAY[1..GVL_KbusRest.gc_uiMaxAnalog]  OF UINT;
    axDO          : ARRAY[1..GVL_KbusRest.gc_uiMaxDigital] OF BOOL;  // confirmed by the gateway
    auiAO         : ARRAY[1..GVL_KbusRest.gc_uiMaxAnalog]  OF UINT;  // confirmed by the gateway
    xOnline       : BOOL;                                // FALSE after 3 failed exchanges in a row
    udiExchanges  : UDINT;
    udiErrors     : UDINT;
    tLastExchange : TIME;                                // duration of the last complete exchange
    iLastStatus   : INT;                                 // HTTP status of the last request
    sLastError    : STRING(80);
END_VAR
VAR
    fbHttp        : FB_HttpTransaction;
    fbInterval    : TON;
    abTx          : ARRAY[0..1535] OF BYTE;
    udiTx         : UDINT;
    iState        : INT;                                 // 0 wait, 1 PATCH DO, 2 PATCH AO, 3 GET
    iPass         : INT;
    iExpected     : INT;
    uiErrStreak   : UINT;
    tStart        : TIME;
    xFirstId      : BOOL;
    i             : UINT;
    // parser
    p             : POINTER TO BYTE;
    udiN          : UDINT;
    diPos         : DINT;
    udiPos        : UDINT;
    uiIdx         : UINT;
    udiVal        : UDINT;
    xDigits       : BOOL;
END_VAR

// --- implementation --------------------------------------------------------
IF NOT xEnable THEN
    fbHttp(xExecute := FALSE);
    xOnline := FALSE;
    iState := 0;
    RETURN;
END_IF

uiNumDI := MIN(uiNumDI, GVL_KbusRest.gc_uiMaxDigital);
uiNumDO := MIN(uiNumDO, GVL_KbusRest.gc_uiMaxDigital);
uiNumAI := MIN(uiNumAI, GVL_KbusRest.gc_uiMaxAnalog);
uiNumAO := MIN(uiNumAO, GVL_KbusRest.gc_uiMaxAnalog);

// ---------------------------------------------------------------- start
IF iState = 0 THEN
    fbInterval(IN := TRUE, PT := tInterval);
    IF fbInterval.Q THEN
        fbInterval(IN := FALSE);
        tStart := TIME();
        IF uiNumDO > 0 THEN iState := 1; ELSIF uiNumAO > 0 THEN iState := 2; ELSE iState := 3; END_IF
        iExpected := -1;                                  // build the request below
    END_IF
END_IF

// up to 3 requests per task cycle: a step starts as soon as the previous one finished
FOR iPass := 1 TO 3 DO
IF iState = 0 THEN
    EXIT;
END_IF

// ---------------------------------------------------------------- build request
IF iExpected = -1 THEN
    udiTx := 0;
    CASE iState OF
    1:  // PATCH all DO: {"data":{"type":"parameters","id":"...","attributes":{"value":[true,false,...]}}}
        F_AppendStr(ADR(abTx), SIZEOF(abTx), 'PATCH /wda/parameters/0-0-kbus-digitaloutputvalues HTTP/1.0$R$N', udiTx);
        F_AppendStr(ADR(abTx), SIZEOF(abTx), 'Content-Type: application/vnd.api+json$R$N$R$N', udiTx);
        F_AppendStr(ADR(abTx), SIZEOF(abTx), '{"data":{"type":"parameters","id":"0-0-kbus-digitaloutputvalues",', udiTx);
        F_AppendStr(ADR(abTx), SIZEOF(abTx), '"attributes":{"value":[', udiTx);
        FOR i := 1 TO uiNumDO DO
            IF i > 1 THEN F_AppendStr(ADR(abTx), SIZEOF(abTx), ',', udiTx); END_IF
            IF axDOSet[i] THEN F_AppendStr(ADR(abTx), SIZEOF(abTx), 'true', udiTx);
            ELSE               F_AppendStr(ADR(abTx), SIZEOF(abTx), 'false', udiTx);
            END_IF
        END_FOR
        F_AppendStr(ADR(abTx), SIZEOF(abTx), ']}}}', udiTx);
        iExpected := 204;
    2:  // PATCH all AO
        F_AppendStr(ADR(abTx), SIZEOF(abTx), 'PATCH /wda/parameters/0-0-kbus-analogoutputvalues HTTP/1.0$R$N', udiTx);
        F_AppendStr(ADR(abTx), SIZEOF(abTx), 'Content-Type: application/vnd.api+json$R$N$R$N', udiTx);
        F_AppendStr(ADR(abTx), SIZEOF(abTx), '{"data":{"type":"parameters","id":"0-0-kbus-analogoutputvalues",', udiTx);
        F_AppendStr(ADR(abTx), SIZEOF(abTx), '"attributes":{"value":[', udiTx);
        FOR i := 1 TO uiNumAO DO
            IF i > 1 THEN F_AppendStr(ADR(abTx), SIZEOF(abTx), ',', udiTx); END_IF
            F_AppendStr(ADR(abTx), SIZEOF(abTx), UINT_TO_STRING(auiAOSet[i]), udiTx);
        END_FOR
        F_AppendStr(ADR(abTx), SIZEOF(abTx), ']}}}', udiTx);
        iExpected := 204;
    3:  // GET all value arrays in ONE request
        F_AppendStr(ADR(abTx), SIZEOF(abTx), 'GET /wda/parameters?filter[id]=', udiTx);
        xFirstId := TRUE;
        IF uiNumDI > 0 THEN
            F_AppendStr(ADR(abTx), SIZEOF(abTx), '0-0-kbus-digitalinputvalues', udiTx); xFirstId := FALSE;
        END_IF
        IF uiNumDO > 0 THEN
            IF NOT xFirstId THEN F_AppendStr(ADR(abTx), SIZEOF(abTx), ',', udiTx); END_IF
            F_AppendStr(ADR(abTx), SIZEOF(abTx), '0-0-kbus-digitaloutputvalues', udiTx); xFirstId := FALSE;
        END_IF
        IF uiNumAI > 0 THEN
            IF NOT xFirstId THEN F_AppendStr(ADR(abTx), SIZEOF(abTx), ',', udiTx); END_IF
            F_AppendStr(ADR(abTx), SIZEOF(abTx), '0-0-kbus-analoginputvalues', udiTx); xFirstId := FALSE;
        END_IF
        IF uiNumAO > 0 THEN
            IF NOT xFirstId THEN F_AppendStr(ADR(abTx), SIZEOF(abTx), ',', udiTx); END_IF
            F_AppendStr(ADR(abTx), SIZEOF(abTx), '0-0-kbus-analogoutputvalues', udiTx);
        END_IF
        F_AppendStr(ADR(abTx), SIZEOF(abTx), ' HTTP/1.0$R$N$R$N', udiTx);
        iExpected := 200;
    END_CASE
    fbHttp.pRequest := ADR(abTx);
    fbHttp.udiRequestLen := udiTx;
    fbHttp(xExecute := FALSE);                            // FALSE -> TRUE in the same cycle:
END_IF                                                    // the request starts at once

// ---------------------------------------------------------------- run request
IF iState > 0 THEN
    fbHttp(xExecute := TRUE, sHost := sHost, uiPort := uiPort, tTimeout := tTimeout);
    IF fbHttp.xDone OR fbHttp.xError THEN
        iLastStatus := fbHttp.iStatus;
        IF fbHttp.xDone AND (fbHttp.iStatus = iExpected) THEN
            IF iState = 3 THEN
                // ---- parse the GET answer: per value array find its id, then "value":[...]
                p := fbHttp.pBody;
                udiN := fbHttp.udiBodyLen;
                // digital arrays: [true,false,...]
                FOR i := 1 TO 2 DO
                    IF i = 1 THEN diPos := F_FindBytes(p, udiN, 0, '"id":"0-0-kbus-digitalinputvalues"');
                    ELSE          diPos := F_FindBytes(p, udiN, 0, '"id":"0-0-kbus-digitaloutputvalues"');
                    END_IF
                    IF diPos >= 0 THEN
                        diPos := F_FindBytes(p, udiN, TO_UDINT(diPos), '"value":[');
                    END_IF
                    IF diPos >= 0 THEN
                        udiPos := TO_UDINT(diPos) + 9;
                        uiIdx := 1;
                        WHILE (udiPos < udiN) AND (p[udiPos] <> 93) DO          // up to ']'
                            IF (p[udiPos] = 116) OR (p[udiPos] = 102) THEN      // 't' / 'f'
                                IF uiIdx <= GVL_KbusRest.gc_uiMaxDigital THEN
                                    IF i = 1 THEN axDI[uiIdx] := (p[udiPos] = 116);
                                    ELSE          axDO[uiIdx] := (p[udiPos] = 116);
                                    END_IF
                                END_IF
                                uiIdx := uiIdx + 1;
                                IF p[udiPos] = 116 THEN udiPos := udiPos + 4; ELSE udiPos := udiPos + 5; END_IF
                            ELSE
                                udiPos := udiPos + 1;                           // ',' or space
                            END_IF
                        END_WHILE
                    END_IF
                END_FOR
                // analog arrays: [0,16384,...]
                FOR i := 1 TO 2 DO
                    IF i = 1 THEN diPos := F_FindBytes(p, udiN, 0, '"id":"0-0-kbus-analoginputvalues"');
                    ELSE          diPos := F_FindBytes(p, udiN, 0, '"id":"0-0-kbus-analogoutputvalues"');
                    END_IF
                    IF diPos >= 0 THEN
                        diPos := F_FindBytes(p, udiN, TO_UDINT(diPos), '"value":[');
                    END_IF
                    IF diPos >= 0 THEN
                        udiPos := TO_UDINT(diPos) + 9;
                        uiIdx := 1;
                        udiVal := 0;
                        xDigits := FALSE;
                        WHILE udiPos < udiN DO
                            IF (p[udiPos] >= 48) AND (p[udiPos] <= 57) THEN     // '0'..'9'
                                udiVal := udiVal * 10 + (p[udiPos] - 48);
                                xDigits := TRUE;
                            ELSIF (p[udiPos] = 44) OR (p[udiPos] = 93) THEN     // ',' or ']'
                                IF xDigits AND (uiIdx <= GVL_KbusRest.gc_uiMaxAnalog) THEN
                                    IF i = 1 THEN auiAI[uiIdx] := UDINT_TO_UINT(udiVal);
                                    ELSE          auiAO[uiIdx] := UDINT_TO_UINT(udiVal);
                                    END_IF
                                END_IF
                                uiIdx := uiIdx + 1;
                                udiVal := 0;
                                xDigits := FALSE;
                                IF p[udiPos] = 93 THEN EXIT; END_IF
                            END_IF
                            udiPos := udiPos + 1;
                        END_WHILE
                    END_IF
                END_FOR
                // exchange complete
                udiExchanges := udiExchanges + 1;
                tLastExchange := TIME() - tStart;
                uiErrStreak := 0;
                xOnline := TRUE;
                iState := 0;
            ELSIF (iState = 1) AND (uiNumAO > 0) THEN
                iState := 2;
            ELSE
                iState := 3;
            END_IF
            iExpected := -1;
        ELSE
            // 400/409 = request rejected (e.g. more channels than the gateway has),
            // 403 = writes disabled, 404 = old gateway without wdx, xError = network
            udiErrors := udiErrors + 1;
            uiErrStreak := uiErrStreak + 1;
            xOnline := uiErrStreak < 3;
            IF fbHttp.xDone THEN
                sLastError := CONCAT('HTTP ', INT_TO_STRING(fbHttp.iStatus));
            ELSE
                sLastError := fbHttp.sErrorText;
            END_IF
            iState := 0;                                  // next exchange starts from step 1
            iExpected := -1;
        END_IF
        fbHttp(xExecute := FALSE);
    ELSE
        EXIT;                                             // request still running: continue next cycle
    END_IF
END_IF
END_FOR

// Object type in CODESYS: POU, Program, language ST
// Task: cyclic, 10 ms (MainTask)
//
// WARNING: this switches REAL outputs. Check what is connected to DO1..DO8
// before you start the application.
// ===========================================================================
PROGRAM PLC_PRG
VAR
    fbIo        : FB_WdxKbusIo;
    xRun        : BOOL := FALSE;        // set TRUE online to start the running light
    tStep       : TIME := T#500MS;
    fbStep      : TON;
    uiStep      : UINT := 1;
    i           : UINT;
END_VAR

// --- implementation --------------------------------------------------------
fbStep(IN := xRun AND NOT fbStep.Q, PT := tStep);
IF fbStep.Q THEN
    uiStep := (uiStep MOD 8) + 1;
END_IF
FOR i := 1 TO 8 DO
    fbIo.axDOSet[i] := xRun AND (i = uiStep);
END_FOR

// KBus I/O through the wdx data layer: PATCH DO array + one GET per exchange
fbIo(xEnable := TRUE, uiNumDI := 0, uiNumDO := 8, uiNumAI := 0, uiNumAO := 0);
